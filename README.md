## The entry

One funny single-line excuse a developer gives when code breaks in production:

> Production is down because the fix for production being down is in the deploy that took production down.

## How it works

`main.py` writes the line above to `/output/entry.txt`. That is the whole
program: one text, 104 characters, no dependencies, no network.

Run it locally:

```sh
python3 main.py
cat /output/entry.txt
```
